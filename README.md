## 📁 Estructura del Portafolio

Este repositorio contiene los ejercicios realizados de la asignatura Aplicaciones Web Progresivas:

- **`Practica1/`**: Web App Manifest, metadatos de instalación e integración del paquete de iconos (192x192 y 512x512).
- **`Practica2/`**: Maquetado del App Shell responsivo (Header, navegación y contenido) y activación de Splash Screen nativa.
- **`Practica3/`**: Registro asíncrono del Service Worker, control del ciclo de vida (`install`, `activate`, `fetch`) e integración con IndexedDB.
- **`Practica4/`**: Uso de la Cache API con estrategia estática **Cache-First** para el App Shell.
- **`Practica5/`**: Intercepción de peticiones con fallback offline y renderizado de vista alternativa (`offline.html`).
